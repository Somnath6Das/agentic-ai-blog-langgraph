# Welcome to your Expo app 👋

## Get started

1. Install dependencies

   ```bash
   npm install expo
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Build Command

npm install -g eas-cli

eas -v

eas login

eas whoami

eas init

eas update:configure

eas build:configure

eas build --profile preview --platform android

## development build

eas build --profile development --platform android
